# ClawAgents Desktop v0.4.32

## Summary

- **Context Mode restored:** fixes the MCP session-timeout incompatibility that caused chat turns to fail with `unsupported operand type(s) for +: 'float' and 'datetime.timedelta'` when Context Mode was enabled.
- **Reliable development startup:** repairs stale or incomplete local backend environments before launching the desktop app.

## Install

Download the `ClawAgents Desktop_0.4.32_aarch64.dmg` asset below, open it, and drag ClawAgents Desktop to Applications.

> This build is not Developer ID signed or notarized. macOS may require a right-click → **Open** on first launch.
